# Day 9 — Data Visualization and EDA

## What I learned
- Exploratory Data Analysis (EDA) is used to understand a dataset before modeling.
- Shape, columns, data types, summary statistics, and value counts reveal basic data quality and structure.
- Histograms help inspect the distribution of a numeric feature.
- Scatter plots help inspect relationships between two numeric variables.
- Correlation can indicate linear association, but it does not prove causation.

## What I practiced
- Loaded the study-progress dataset with Pandas.
- Inspected dataset shape and column names.
- Generated descriptive statistics for numeric columns.
- Counted categories in `study_mode`.
- Calculated a numeric correlation matrix.

## ML intuition
EDA helps decide which features may be useful, which transformations may be needed, and whether unusual values or patterns need investigation before training a model.
