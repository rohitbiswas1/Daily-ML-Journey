# Day 1 — Introduction to Machine Learning

## What is Machine Learning?
Machine Learning (ML) is a branch of artificial intelligence where computers learn patterns from data and use those patterns to make predictions or decisions without being explicitly programmed for every rule.

## Traditional Programming vs Machine Learning

**Traditional programming:**
`Rules + Data → Output`

**Machine learning:**
`Data + Expected Output → Learned Model`

The learned model can then be used to make predictions on new data.

## Main Types of Machine Learning

### 1. Supervised Learning
The training data contains input features and known target values.

Examples:
- Predicting house prices
- Detecting whether an email is spam
- Classifying a plant disease

### 2. Unsupervised Learning
The algorithm works with data without predefined target labels and tries to discover useful structure.

Examples:
- Customer segmentation
- Grouping similar documents
- Finding unusual data points

### 3. Reinforcement Learning
An agent learns by interacting with an environment and receiving rewards or penalties for its actions.

Examples:
- Game-playing agents
- Robot navigation
- Resource allocation

## Important ML Vocabulary

| Term | Meaning |
|---|---|
| Feature | An input variable used by a model |
| Target/Label | The value a supervised model tries to predict |
| Training data | Data used to learn model parameters |
| Test data | Unseen data used to evaluate the model |
| Model | The learned mathematical relationship used for prediction |
| Prediction | The output produced by a trained model |
